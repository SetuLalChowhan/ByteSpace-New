# ByteSpace 🚀

A modern online learning and course marketplace platform built with Next.js (App Router), React, and Tailwind CSS.

---

## 📌 What I Did

### 1. **Project Setup & Design System**
- Initialized the Next.js project with TypeScript and App Router architecture.
- Configured **Tailwind CSS v4** with custom theme tokens, typography, and utility classes.
- Integrated smooth entrance and scroll animations using **Framer Motion**.

### 2. **Landing Page Sections**
- **Hero Section**: Engaging headline, call-to-action buttons, and interactive animations.
- **Brand / Partner Section**: Interactive marquee showcasing trusted brands.
- **Discover Section**: Filterable course cards highlighting popular and trending courses.
- **Explore Categories**: Multi-category grid for browsing topics (Tech, Design, Business, etc.).
- **Professional Section**: Mentors & statistics showcase featuring animated counters with `react-countup`.
- **Review / Testimonials**: Student reviews, ratings, and social proof.
- **CTA Section**: Conversion banner encouraging users to join or become creators.

### 3. **Pages & Routes**
- **Home Page (`/`)**: Complete landing experience assembled with motion wrappers.
- **Courses (`/courses`)**: Course browsing and catalog view.
- **Creators (`/creators`)**: Dedicated instructor/creator discovery page.
- **Cart (`/cart`)**: Shopping cart checkout flow.
- **Authentication (`/login`, `/register`)**: Dedicated auth layout and forms.

### 4. **Reusable UI Components**
- Custom buttons, typography helpers, motion wrappers (`MotionSection`), and course cards.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Library:** [React](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Utilities:** `react-countup`, `react-fast-marquee`, `react-hook-form`

## ⚡ Getting Started

1. **Clone the repository:**
   ```bash
   git clone <repo-url>
   cd ByteSpace-New
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

   Live URL :https://byte-space-new-theta.vercel.app
